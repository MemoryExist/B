# 问题2：第二个检测点的选择（MATLAB 实现）

本目录完成 2026 高教社杯全国大学生数学建模竞赛 B 题“无线电干扰源的快速自动定位与清除”
**问题二**：已知某全向干扰源在第一个检测点处测得的示向度，给出第二个检测点的选择策略
与候选区域，以获得较好的定位效果。全部代码仅依赖基础 MATLAB（本机实测于 R2025a），
不使用 Optimization Toolbox / Global Optimization Toolbox / Parallel Computing Toolbox
或任何第三方包。

## 三、默认假设与关键参数（见 config_problem2.m）

1. **默认情形**：目标圆域在局部坐标下**不裁切**首次示向度扇形，源可行域取“标准完整扇区”
   `D = {u≥0, −u·tanδ ≤ v ≤ u·tanδ, 5 < √(u²+v²) ≤ 1500}`，δ=1°。若提供目标圆域的
   局部位置，可设 `cfg.crop_enabled=true`（源域再与目标圆相交；此时候选域退化为默认
   E 的安全子区域，方向范围保守取全圆）。
2. 局部坐标：第一检测点 S1=(0,0)，第一次实际示向度沿 +x 轴。全局/局部转换见
   `transform/local_to_global.m`、`transform/global_to_local.m`。
3. 保守安全候选域 E（保证第二次必能收到信号）为四圆盘之交：
   `(x−r·cosδ)² + (y−s·r·sinδ)² ≤ 1000²`，r∈{5,1500}, s∈{±1}。
4. 真实主评价 `f1(P) = sup_β ρ(P,β)`（β 为所有可能正常读数），ρ 为定位区域的最小包围圆半径。
5. 近似指标 `f1_hat`（一阶线性化端点公式）仅用于**排序**，不是严格必要条件。
6. 点对下界与弦下界（f1 ≥ 25.73 米，E 内恒成立）提供**数学排除依据**。
7. 算法参数：粗评间隙 2 米、精评间隙 0.1 米、角度箱初始半宽 1°、圆弧多边形 2048 边、
   粗评预算 160 次/点、精评预算 900 次/点、精度让步 τ=1 米、模式搜索步长 48→4 米。
   均为可配置参数，非题目给定常数。

## 四、实测结果（R2025a，标准完整扇区，固定种子 42）

- 回归测试 P=(750,600)：f1 ∈ [59.332, 59.374] 米，最坏读数 319.129°（与既有临时验证
  程序的 [59.3367, 59.4210] 一致且区间更窄）。
- 数值最优参考 m_hat = **55.729** 米，P_best = **(818.47, 580.15)**，上下界
  [55.657, 55.729]（间隙 0.073 米），最坏读数 317.33°。
- 分层选择（τ=1 米）：F_τ 内距离最短点 P_f2 = **(799.22, -589.98)**，移动距离
  993.39 米、移动时间 198.68 秒。
- 基线（仅用近似指标）：P_hat = (818.47, 580.15)，f1_hat = 60.78 米，真实
  [55.657, 55.729] 米。
- 统计：候选 411 个，粗评 32 个，评价调用 106 次、缓存命中
  44 次、提前淘汰 26 次、点对下界排除 5 次；搜索实测耗时
  6.1 秒；全流程（验证+搜索+敏感性+绘图）45.3 秒。
- 敏感性：τ ∈ {0,1,3} 与候选数量 {291, 571} 的结果见
  `results/sensitivity.csv`。

## 五、算法与实现要点

- **固定 P 真实评分上下界**（`eval/eval_P_bounds.m`）：把可行读数范围 Θ(P) 安全覆盖后
  分成角度箱，箱上界用加宽楔形 W(P;β;δ+η) 的**外近似**（外切圆弧多边形 + 减去近源孔
  的**内接**多边形，保证仍为超集），箱中点采样用**内近似**（内接圆弧多边形 + 减去近源
  孔的**外接**多边形，保证仍为子集）给下界；每次细分上界最大的箱。终止条件：上下界差
  ≤ 指定精度 / 下界超过淘汰阈值（提前淘汰）/ 达到预算（返回未收敛状态，不伪装收敛）。
  Θ(P) 的求法：P 在 D 内部取全圆；否则方向跨度由四角点方向极值给出（P∈E 时 P 在
  1500 圆内，无切点），并加 0.05° 数值余量。
- **最小包围圆**（`mec/welzl_mec.m`）：Welzl 随机增量算法迭代实现（避免递归深度问题），
  处理单点/两点/共线/钝角三角形/重复点/近共线点；验证套件含枚举对拍。
- **两阶段选点**（`search/outer_search.m`）：候选生成（网格+随机，不做全 E 密集扫描）→
  f1_hat 排序 + 多样化起点 → 粗评建立 U_best → 点对下界数学排除 → 带 E 约束的模式搜索
  （不假设凸）→ 少量候选精评复核 → F_τ 分层选择。全流程状态缓存（毫米量化键），提高
  精度时从缓存角度箱状态**继续细分**。
- **验证**（`verify/verify_problem2.m`）：51 项断言，见问题片段 §9。

## 六、算法限制与未证明事项（论文中如实声明）

1. m_hat 是**数值最佳参考**，不是已证明的全局最优（未做全局最优证明）。
2. 密角度采样、离散见证点只用于核验/下界构造，不是连续角域上界的证明。
3. f1_hat 不是真实 f1 的上/下界，不能作为排除候选点的必要条件。
4. 目标圆域裁切情形采用保守 E（安全子区域），未求最大安全区域。
5. 上下界基于浮点实现与显式集合包含关系，不是区间算术形式化认证。
6. 不把“角度成功比例”当作概率；结论均为最坏情形意义上的保证。
7. 移动成本只优化到第二站的 ||P||；若讨论直到清除的总路程需另加 P→观测后包围圆圆心
   的路程（见 problem2_section.tex §9）。
