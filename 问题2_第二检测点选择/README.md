# 问题二：第二检测点选择

采用“近似排序 + 必要条件淘汰 + 少量候选精评”，保留精度优先、兼顾移动路程的思路。只依赖基础 MATLAB；验证环境为 R2025a。

## 运行

进入本目录，在 MATLAB 中执行：

```matlab
main_problem2             % 搜索、三张图、CSV/MAT 和论文数据
main_problem2('verify')   % 单独验证几何、上下界、缓存等
main_problem2('full')     % 验证、默认流程、敏感性分析
```

也可以用 Bash：`bash run_problem2.sh`。附加参数 `verify` / `full` 选择模式。
其他机器可用环境变量 `MATLAB_BIN` 指定 MATLAB 可执行文件。

运行后，用 XeLaTeX 编译 `preview_problem2.tex` 两次即可更新论文预览。
将论文片段合入总论文时，将 `\qtwopath`NaN`config_problem2.m` | 几何条件、评价容差、候选数量和计算预算 |
| `search/outer_search.m` | 完整选点过程，先低上界精评，再筛选短路程点 |
| `eval/eval_P_bounds.m` | 给固定点计算最坏包围半径的上下界，可续算 |
| `geo/build_J_region.m` | 用集合内外近似保证上下界方向，处理两个 5 米排除区 |
| `mec/welzl_mec.m` | 增量支撑集包围圆算法；沿用旧文件名，不声称线性复杂度 |
| `problem2_section.tex` | 模型、证明、算法与自动引用的运行结果 |

单独评价一点：

```matlab
addpath(genpath(pwd));
cfg = config_problem2;
r = eval_P_bounds([750;600], cfg);
[r.L, r.U]                 % 最坏评分的上下界
r.status                   % converged / pruned / budget
[circleRadius, center] = region_mec([750;600], ...
    deg2rad(319.13), cfg.delta, 'outer', cfg);
```

最后一条命令针对一个已知读数返回覆盖圆及圆心；它不代表所有可能读数的最坏情况。
`U-L` 是评分的不确定区间宽度，不是干扰源位置误差。

## 模型与输出

- 首站为局部原点，首次测得方向沿正 x 轴。默认源域是距离 5～1500 米、半角 1° 的完整扇区，距离 5 米处按正常观测排除。
- E 用四个半径 1000 米的圆盘约束，保证对所有可能源位置均能接收信号。若第二站离源不超过 5 米，则直接进入光学分支。
- `f1(P)` 是所有可能正常读数下的最小包围圆半径的上确界。端点线性近似只排序；见证点下界才支持淘汰。
- 先比较精度，再允许默认 1 米让步，在已收敛精评点中选路程最短者。结果是有限候选中的数值选择，未证明全局最优，也未完整恢复连续优良区域。
- 如需加入半径 1800 米的目标圆域，配置 `crop_enabled`、`crop_center`、`crop_radius`。圆心须用局部坐标；此时沿用原 E 作为保守子区域。内切圆下界只在该圆盘仍属于 D 时使用。

主要结果在 `results/final_summary.csv`，全部粗候选状态在 `candidates.csv`，精评点在 `fine_points.csv`。
`out.mat` 保存参数、角度箱缓存及结果；`problem2_numbers.tex` 由相同数据自动生成，避免手写论文数字。
默认只生成概览、代表读数的覆盖圆、上下界收敛三张图。验证与敏感性结果单独保存。

## 本次修订

修正了外近似错误挖除孔外合法点、淘汰缓存无法续算、毫米坐标缓存碰撞、
无采样角被误报为空集、整圆初始角度箱可能漏角，以及裁切后仍使用失效下界等问题。
覆盖示意改用外近似包围圆，论文用解析推导证明近似指标的径向凸性。

源域圆弧改为只对 2° 弧分 64 段，固定几何缓存复用；局部搜索与精评都有预算。
默认不再重复运行密角度扫描和候选数量实验。
上下界基于集合包含关系与双精度数值实现，未使用区间算术；未达到容差的点会保留
`budget` 状态，不参与最终精评选择。收紧容差后如仍不收敛，应同时检查预算与几何分辨率。

对完整扇区，可证明任意 P∈E 的最坏包围半径至少为 25.73 米，因此不能保证仅用两次
测向就满足 20 米光学覆盖要求。具体最优数值请以本次运行结果为准。
