\subsection{问题的背景}
无线电是科技信息时代的重要工具，广泛应用于新闻通讯、商业交互、军事联络等诸多领域。
无线电干扰会影响通信设备及无线电系统的正常运行，快速定位并清除干扰源是频谱管理中的重要任务。
传统方法分为初步监测、区域性排查、精准定位三阶段，其中可依据固定监测站、移动监测车或无人机进行大范围初筛，

某公司拟研发一个搭载于机器狗的干扰源自动定位清除系统，通过利用测向设备获取信号场强及方向等信息，自主搜索并定位干扰源。
已知干扰源位于以原点为圆心、半径1800 m的圆形区域内，数量和具体位置均未知。以正东方向为x正半轴，正北方向为y轴正半轴建立平面直角坐标系。

\subsection{问题1：交会区域直径的计算}

为了求得定位区域直径，我们首先需要通过交会定位法确定并表示出该区域。确定该区域后我们需要给出直径的算法，而对区域内每两点求距离计算量过于庞大，因此我们将在下文中通过确认定位区域的闭凸性和有界性
证明它是闭凸多边形，随后证明直径必然是其对角线中的一条来大大减少计算量。最后我们将多种Matlab求解方法对比，选择了更加适合该题目的向量暴力求解方法。

\subsubsection{交会定位区域的建立}

\caption{流程图}

设共有 $n$ 个检测点，其坐标分别为 $S_i=(x_i,y_i)$，$i=1,2,\ldots,n$。
对应测得的示向度为 $\theta_i\in[0^\circ,360^\circ)$。根据附录2，测向机的示向度与干扰源真实方位角之间的误差绝对值不超过 $\tau=1^\circ$。
设干扰源真实位置为 $G$，则在第 $i$ 个检测点处，其真实方位角 $\beta_i=\arg(G-S_i)$
满足
$\left|\operatorname{wrap}(\beta_i-\theta_i)\right|\leq \tau$。
其中偏差的取值通过公式
\[
\operatorname{wrap}(x) = x-360^\circ \left\lfloor\frac{x+180^\circ}{360^\circ}\right\rfloor .
\]

统一折算到 $(-180^\circ,180^\circ]$ 区间内，利用wrap函数避免角度周期性带来的误判。

而对于每个检测点 $S_i$ ，干扰源一定落在以 $S_i$ 为顶点、以 $\theta_i-\tau$ 和 $\theta_i+\tau$ 为两条边界射线的角形区域内。我们把这块区域记为第 $i$ 个检测点的视界楔形
\begin{equation}
W_i= \left\{ P: P=S_i \ \text{或}\ \left|\operatorname{wrap} \bigl(\arg(P-S_i)-\theta_i\bigr)\right| \leq\tau \right\}.
\end{equation}

交会定位区域实际上就是所有视界楔形的交集

\begin{equation}
\mathcal R=\bigcap_{i=1}^n W_i.
\end{equation}

回到题设，干扰源的真实位置 $G$ 必须同时落进每一个检测点的视界楔形中，即 $G\in W_i$（$i=1,\ldots,n$），
于是立即可以得到：

\begin{equation}
G\in\mathcal R.
\end{equation}

也就是说，$\mathcal R$ 正是干扰源位置的理论可行域。

\subsubsection{定位区域的闭凸性证明}

为了便于进一步计算定位区域的几何性质，对每一个检测点 $S_i$ 建立局部正交坐标系。定义
\begin{equation}
u_i=(\cos\theta_i,\sin\theta_i),\qquad v_i=(-\sin\theta_i,\cos\theta_i),
\end{equation}

其中 $u_i$ 为测得方向的单位向量，$v_i$ 为其逆时针旋转 $90^\circ$ 后的单位向量。

对任意待测位置 $P$，记 $d=P-S_i$ ，再把它在这组局部基下拆开，即
\begin{equation}
d=\xi_i u_i+\eta_i v_i,
\end{equation}

其中 $\xi_i=d\cdot u_i$，$\eta_i=d\cdot v_i$。
$\xi_i$ 表示点 $P$ 沿示向度方向的纵向距离，$\eta_i$ 表示偏离示向度方向的横向距离。

当 $d\neq0$ 且 $\xi_i>0$ 时，方位角和 $(\xi_i,\eta_i)$ 之间有以下关系：

\begin{equation}
\arg(d)-\theta_i = \arctan\frac{\eta_i}{\xi_i}.
\end{equation}

两边取绝对值，测向误差约束就化成了对横向与纵向距离之比的限制

\begin{equation}
\left|\arg(d)-\theta_i\right|\leq\tau \iff \left|\frac{\eta_i}{\xi_i}\right| \leq\tan\tau.
\end{equation}

再把目标一定位于检测点前方这一条件 $\xi_i\geq0$ 一并纳入，整理后可得

\begin{equation}
W_i= \left\{ S_i+\xi u_i+\eta v_i: \xi\geq0,\; |\eta|\leq\xi\tan\tau \right\}.
\end{equation}

进一步地，$|\eta_i|\leq\xi_i\tan\tau$ 等价于

\[
\eta_i\leq\xi_i\tan\tau, \qquad -\eta_i\leq\xi_i\tan\tau.
\]

由于 $\xi_i$ 和 $\eta_i$ 均为位置坐标 $P=(x,y)$ 的线性函数，因此上面这两个条件都可以直接写成半平面不等式的形式。

具体地，令
\begin{equation}
e_i^\pm= \left( \cos(\theta_i\pm\tau), \sin(\theta_i\pm\tau) \right),
\end{equation}

则楔形两条边界射线分别为

\[
S_i+t e_i^\pm,\qquad t\geq0.
\]

这两条边界所在直线的交点，即楔顶，为

\begin{equation}
A_i = S_i+\frac{1}{\cos\tau}u_i.
\end{equation}

定义单位法向量

\[
n_i^\pm = \left( \sin(\theta_i\mp\tau), -\cos(\theta_i\mp\tau) \right),
\]

则视界楔形可表示为两个半平面的交：

\begin{equation}
W_i= \left\{ P:n_i^+\cdot P\leq n_i^+\cdot A_i \right\} \cap \left\{ P:n_i^-\cdot P\leq n_i^-\cdot A_i \right\}.
\end{equation}

因此，交会定位区域可以进一步表示为

\begin{equation}
\mathcal R = \bigcap_{j=1}^{2n} \left\{ P:n_j\cdot P\leq c_j \right\}.
\end{equation}

而由于有限个闭半平面的交仍为闭凸集，因此$\mathcal R$ 一定是闭凸区域。

\subsubsection{定位区域有界性的判定}

 $\mathcal R$ 是闭凸区域：当其有界时，$\mathcal R$ 即为一个凸多边形，且边界至多包含 $2n$ 条边。
 而凸多边形的直径是易求的，因此我们将讨论 $\mathcal R$ 是否有界。

由于测向误差的存在，当各检测点的示向度过于接近时，多个视界楔形可能存在共同的延伸方向，使得交会定位区域向无穷远处扩张：

设非零向量 $\xi$ 是 $\mathcal R$ 的一个逃逸方向，即存在 $P_0\in\mathcal R$，使得 $P_0+t\xi\in\mathcal R$（$\forall t\geq0$）。
对于第 $i$ 个视界楔形来说，它能无限延伸的方向，恰好是那些与示向度 $\theta_i$ 夹角不超过 $\tau$ 的方向，即

\begin{equation}
\left| \operatorname{wrap} \left( \theta_i-\arg\xi \right) \right| \leq\tau
\end{equation}
换言之，$\mathcal R$ 存在非零逃逸方向，等价于存在某个方向 $\varphi$ 能够覆盖所有检测点的示向度：
\[
\left| \operatorname{wrap}(\theta_i-\varphi) \right| \leq\tau, \qquad i=1,\ldots,n.
\]

把各个示向度看成单位圆周上的点，上述条件正好对应“它们能被一条长度为 $2\tau$ 的弧覆盖”。
为定量描述，定义这些方向点的最小包围弧长度为：

\begin{equation}
\alpha(\Theta) = 360^\circ- \max_k \left( \theta_{(k+1)}-\theta_{(k)} \right)_{360},
\end{equation}

其中 $\theta_{(k)}$ 为示向度升序排列后的结果，下标按圆周循环，$(\cdot)_{360}$ 表示模 $360^\circ$ 后落入 $[0^\circ,360^\circ)$ 的环间隔。

因此可知，若所有示向度都能塞进某条长度为 $2\tau$ 的弧里，就存在共同逃逸方向，定位区域无界；反之，只要最小包围弧长度超过 $2\tau$，就找不到共同逃逸方向，区域必然有界。于是得到有界性判据
\begin{equation}
\mathcal R\ \text{有界} \iff \alpha(\Theta)>2\tau.
\end{equation}

退化到只有两个检测点的情形，先算出两示向度的最小夹角
\begin{equation}
\Delta\theta = \left| \operatorname{wrap}(\theta_2-\theta_1) \right| <180^\circ.
\end{equation}

此时显然有 $\alpha(\Theta)=\Delta\theta$，代入上面的判据，立刻得到
\begin{equation}
\mathcal R\ \text{有界} \iff \Delta\theta>2\tau=2^\circ.
\end{equation}

也就是说，当两个检测点观测到的方向夹角不超过 $2^\circ$ 时，交会区域可能沿共同方向无限延伸，不能直接定义有限直径。遇到这种情况，则需给定位区域补上有界化条件。

\subsubsection{定位区域直径的计算}

当上述有界性条件成立时它就是紧凸多边形，直径自然有定义，即
\begin{equation}
D=\operatorname{diam}\mathcal R = \max_{P,Q\in\mathcal R}|P-Q|.
\end{equation}

然而直接对区域上所有点对求最大距离仍然十分困难。但我们可以根据 $\mathcal R$ 是凸多边形，
将其连续优化进一步压成有限个顶点对的比较。

设 $\mathcal R$ 的顶点按逆时针方向排列为 $V_1,V_2,\ldots,V_m$。
固定任意 $Q\in\mathcal R$，函数 $f(P)=|P-Q|$ 关于 $P$ 为凸函数。
若 $P$ 落在某条边的内部，可将其写成该边两个端点的凸组合，于是由三角不等式，
至少有一个端点到 $Q$ 的距离不小于 $P$ 到 $Q$ 的距离。这说明最大值一定能在顶点处取到，即：

\begin{equation}
D= \max_{1\leq i<j\leq m}|V_i-V_j|.
\end{equation}

于是，问题一中定位区域直径的计算可以归纳为以下步骤：
\begin{enumerate}
\item 根据每个检测点的坐标 $S_i$、示向度 $\theta_i$ 和误差界 $\tau$，建立两个半平面约束，共得到至多 $2n$ 个半平面；
\item 对这些半平面进行求交，获得定位区域 $\mathcal R$ 的顶点 $V_1,\ldots,V_m$（$m\leq2n$）；
\item 枚举任意两个顶点，计算 $d_{ij}=|V_i-V_j|$，取最大值作为定位区域直径
\begin{equation*}
D=\max_{i<j}d_{ij}.
\end{equation*}
\end{enumerate}

\subsubsection{Matlab求解方法}

在对半平面求交得到 $\mathcal R$ 的顶点 $V_1,\ldots,V_m$（$m\leq2n$） 后，我们需要求解以下非线性规划问题：

\begin{equation}
\begin{aligned}
\max_{V_i, V_j} \quad & \|V_i - V_j\|_2 \\
\text{s.t.} \quad & \begin{cases}
V_i, V_j \in \mathcal{R}, \\
\mathcal{R} = \bigcap_{k=1}^{2n} \left\{ X : n_k \cdot X \leq c_k \right\}, \\
n_k \cdot X \leq c_k \text{ 为半平面的函数表达式}.
\end{cases}
\end{aligned}
\end{equation}

若直接枚举顶点对，直径计算的复杂度为 $O(m^2)$，再代入 $m\leq2n$，可进一步写为 $O(n^2)$。
当顶点已按凸多边形边界顺序排列时，也可以进一步利用旋转卡壳算法将直径计算降至 $O(m)$，而考虑到

\subsubsection{以定位区域直径为直径的圆能否覆盖定位区域}

问题一的第二部分要回答的是：以定位区域直径 $D$ 为直径的圆，是否一定能把整个定位区域罩住？

为此先引入集合 $K$ 的最小覆盖圆半径

\begin{equation}
R_{\mathrm{MEC}}(K) = \min_C\max_{P\in K}|C-P|.
\end{equation}

它衡量的是“用圆罩住 $K$ 所需的最小代价”。注意到区域直径为 $D$，就意味着存在一对点 $A,B\in K$ 满足 $|A-B|=D$。
现在任取一个能覆盖 $K$ 的圆，设圆心为 $C$、半径为 $R$，由三角不等式直接得到

\begin{equation}
D = |A-B| \leq |A-C|+|C-B| \leq2R.
\end{equation}

也就是说，任何覆盖圆的半径都逃不过 $D/2$ 这个下界，故

\begin{equation}
R_{\mathrm{MEC}}(K)\geq\frac D2.
\end{equation}

\begin{figure}[htbp]
\centering
\includegraphics[width=0.3\linewidth]{反例图.png}
\caption{等边三角形反例图}
\label{fig:p1_counterexample}
\end{figure}

但这里要特别注意，上式一般不能取等号，也就不能保证存在一个直径恰好为 $D$ 的圆罩住整个区域。为了说明这一点，可以取边长为 $D$ 的等边三角形作为反例：它的直径确实是 $\operatorname{diam}K=D$，可它的最小覆盖圆是外接圆，半径

\[
R_{\mathrm{MEC}}(K)=\frac D{\sqrt3}.
\]


于是 $2R_{\mathrm{MEC}}(K) = \dfrac{2}{\sqrt3}D >D$。这恰好说明：以定位区域直径 $D$ 为直径的圆一般不能覆盖整个定位区域。

再进一步，由平面上的 Jung 定理，任意直径为 $D$ 的有界集合都满足：

\begin{equation}
\frac D2 \leq R_{\mathrm{MEC}}(K) \leq \frac D{\sqrt3},
\end{equation}

其中等边三角形达到上界。因此，如果需要构造能够保证覆盖整个定位区域的圆形搜索域，
其严格的尺度应采用最小覆盖圆直径 $2R_{\mathrm{MEC}}$，而不能简单地将定位区域直径 $D$ 
直接作为圆的直径。

\subsubsection{确定候选区域}

为求得检测点2所在区域，我们将先选出候选区域，保证候选区域内所有点可以扫描到干扰源所有可能位置，然后
再于候选区域内找到检测点2的最优位置。

以首个检测点为原点，以首次测得的示向度为 $x$ 轴正向，建立局部坐标系。
设第二检测点为 $P=(x,y)$，干扰源为 $G=(u,v)$，误差半角为
$\tau=1^\circ=\pi/180$。干扰源在两次观测之间保持不变。

首次正常观测后，干扰源可能的位置为：
\begin{equation}
E_0=\left\{(u,v):u\ge0,\ |v|\le u\tan\tau,\
5<\sqrt{u^2+v^2}\le1500\right\}.
\label{eq:q2E0}
\end{equation}

为保证第二站接收到信号，利用有效接收半径至少为 $1000$ 米，
选取保守候选区域
\begin{equation}
\begin{aligned}
E &= \left\{P:\sup_{G\in E_0}\|P-G\|\le 1000\right\}
\end{aligned}
\label{eq:q2E_def}
\end{equation}

为满足 $\sup_{G\in E_0}\|P-G\|\le 1000$，等价于要求距离函数 $f(G) = \|P-G\|$ 在区域 $E_0$ 上的最大值不超过 $1000$。而距离函数 $f(G)$ 是关于 $G$ 的连续凸函数，依据凸函数的极值性质，其在有界闭区域上的最大值必然在该区域的顶点处取得。

具体到扇形区域 $E_0$：在极坐标下固定半径 $r$ 时，$f(G)$ 沿圆弧没有内部极大值，最大值只能在极角边界 $\pm\tau$ 处取得；固定极角时，$f(G)$ 关于 $r$ 也是凸的，最大值只能在极径两端取得。因此，$f(G)$ 在 $E_0$ 上的最大值必然在四个角点（即 $r\in\{5,1500\}$ 且极角在 $\pm\tau$ 边界处的 $G_1, G_2, G_3, G_4$ 四个点）处取得。

所以，只需保证这四个顶点到 $P$ 的距离均小于等于 $1000$ 米，即可确保 $E_0$ 内所有点均满足接收要求。这就将无穷多个点 $G$ 的约束严格简化为了四个点的距离约束。

\begin{equation}
\begin{aligned}
E &= \bigcap_{i=1}^{4} \left\{ P : \|P-G_i\| \le 1000 \right\} \\
  &= \bigcap_{\substack{r\in\{5,1500\}\\s\in\{-1,1\}}}
\left\{(x,y):(x-r\cos\tau)^2+(y-sr\sin\tau)^2\le 1000^2\right\}.
\end{aligned}
\label{eq:q2E}
\end{equation}

\subsubsection{以最差包围半径衡量精度}

仅仅有待测区域的确定还不够，我们还需要知道该区域内每个点所交会产生图形的最差包围圆半径的大小来衡量这个位置定位的精度。

记 $W(P;\beta,\tau)$ 为检测点 $P$、中心方向 $\beta$、半角 $\tau$ 的前向楔形。
正常读数 $\beta$ 对应的定位区域为：

\begin{equation}
J(P,\beta)=E_0\cap W(P;\beta,\tau)\cap\{G:\|G-P\|>5\}.
\label{eq:q2J}
\end{equation}

距离源不超过 $5$ 米时，仪器无法给出示向度，应直接采用光学定位与清除。
楔形约束还可改写为两条线性不等式：

\begin{equation}
\left\{
\begin{aligned}
\sin(\beta-\tau)(u-x)-\cos(\beta-\tau)(v-y)&\le0,\\
-\sin(\beta+\tau)(u-x)+\cos(\beta+\tau)(v-y)&\le0.
\end{aligned}
\right.
\end{equation}

由于还包含圆弧和近距离排除区，$J$ 不一定是四边形。

对非空集合 $A$，定义最小包围圆半径
$\rho(A)=\min_c\sup_{G\in A}\|G-c\|$，并用闭包计算相同半径。
所有可能正常读数构成集合 $\Theta(P)$，即：
\begin{equation}
\Theta(P)=\bigcup_{\substack{G\in E_0\\\|G-P\|>5}}
[\arg(G-P)-\tau,\arg(G-P)+\tau],
\label{eq:q2Theta}
\end{equation}
在此基础上，我们定义检测点 $P$ 的“最差包围半径” $f_1(P)$ 为：
\begin{equation}
f_1(P)=\sup_{\beta\in\Theta(P)}\rho(J(P,\beta)).
\label{eq:q2score}
\end{equation}

这里 $f_1(P)$ 评估了所有可能测得的示向度 $\beta$ 所对应定位区域半径的最大值，因此该指标同时考虑了干扰源位置未知性以及测角误差，代表了最差情况的结果。

最理想情况下，若 $\rho(J(P,\beta))\le20$，走到相应圆心即可保证光学定位成功。

然而对完整扇区，实际上不存在满足 $f_1(P)\le20$ 的 $P\in E$。
令
\begin{equation*}
C=\left(\frac{1500}{1+\sin\tau},0\right),\qquad
r_*=\frac{1500\sin\tau}{1+\sin\tau}\approx25.730.
\end{equation*}

圆盘 $B(C,r_*)$ 内切于扇区，且完全位于首站 $5$ 米排除区之外。
由 $P\in E$ 得 $\|P\|\le1005$，而 $\|C\|-r_*>1448$，
所以从 $P$ 指向 $C$ 的射线穿过该圆盘的一条完整直径，
直径上的点距 $P$ 均大于 $5$ 米且与同一读数相容。
因此：

\begin{equation*}
f_1(P)\ge r_*>20,\qquad P\in E.
\end{equation*}

这给出不可行性的下界证明，并不表示最优半径能达到 $r_*$.因此对每个点位置打分来衡量优劣是必要的。

由于原始定义涉及的不可解圆弧与复杂多边形求交，计算量巨大，我们首先引入线性化近似，对候选区域进行粗略打分以筛选大部分无效点，然后再对剩余候选点进行高精度精确打分。

\subsubsection{第一阶段打分（粗筛）}

直接对整个候选区域 $E$ 做高精度几何求交开销极大。因此，我们首先构造一个低成本的极速打分指标，对所有候选点进行近似排序。

由于测向方程中包含非线性的三角函数，直接求解精确的边界交点十分复杂。考虑到实际设备允许的最大测角误差 $\tau = 1^\circ$ 非常小，
因此可以采用小角度近似（$\sin\tau \approx \tau$ 且 $\cos\tau \approx 1$）来简化问题，我们在首条中心射线取参考源 $G=(r,0)$，
对测向方程在 $G$ 点附近作一阶泰勒展开线性化，使原本复杂的非线性定位区域边界被简化为了四条直线，得到一个规范的“位置误差平行四边形”：

\begin{equation*}
|\Delta v|\le r\tau,\qquad
|y\Delta u+(r-x)\Delta v|\le\bigl((r-x)^2+y^2\bigr)\tau .
\end{equation*}

其包围半径（即粗筛阶段的评分公式）为：

\begin{equation}
\widehat\rho(r;P)=\tau
\sqrt{r^2+\frac{\left((r-x)^2+y^2+r|r-x|\right)^2}{y^2}},
\qquad y\ne0.
\label{eq:q2surrogate}
\end{equation}

我们发现该近似模型中，径向最坏误差必然在区间的两端（$r=5$ 或 $r=1500$）取得。
具体的推导过程如下：令

\[
H(r)=(r-x)^2+y^2+r|r-x|
=\max\{x^2+y^2-xr,\ 2r^2-3xr+x^2+y^2\},\quad r\ge0.
\]

首先，函数 $f_1(r) = x^2+y^2-xr$ 是关于 $r$ 的线性函数，因而是凸函数；

函数$f_2(r) = 2r^2-3xr+x^2+y^2$ 是关于 $r$ 的二次函数，其二阶导数为 $4 > 0$，因而是严格凸函数。

由于两个凸函数的逐点最大值仍然是凸函数，所以 $H(r) = \max\{f_1(r), f_2(r)\}$ 必定是非负的凸函数。

其次，对于给定的候选点 $P(x,y)$，打分公式可写为二维向量的欧几里得范数：

\begin{equation}
\widehat\rho(r;P)=\tau \left\| \left( r, \frac{H(r)}{|y|} \right) \right\|_2.
\end{equation}

由欧氏范数在非负象限上的单调性，以及 $r \mapsto r$（线性）和 $r \mapsto H(r)/|y|$（凸且非负）的凸性组合可知，复合函数 $\widehat\rho(r;P)$ 严格保持了关于 $r$ 的凸性。

\textbf{根据凸优化理论的基本定理：凸函数在闭区间 $[5, 1500]$ 上的最大值必然在区间的边界端点处取得}。因此，我们严密推导出第一阶段候选点 $P$ 的最终打分为：
\begin{equation}
\widehat f_1(P)=\max\{\widehat\rho(5;P),\widehat\rho(1500;P)\}.
\end{equation}

这一端点定理极大地减少了搜索空间。但该结论仅适用于线性化指标，不适用于真实的几何区域模型。
因此 $\widehat f_1$ 仅用于第一阶段极速打分排序用以降低计算量；$y=0$ 的奇异点则直接交由第二阶段模型评价。

另从 $E_0$ 中取有限个见证点 $G_i$。
若两点距 $P$ 均大于 $5$ 米，且从 $P$ 看去的夹角不超过 $2\tau$，
则它们可产生同一正常读数，因而
\begin{equation}
\ell_{\rm pair}(P)=
\max_{\substack{i<j,\ \|G_i-P\|,\|G_j-P\|>5\\
\angle(G_i-P,G_j-P)\le2\tau}}
\frac{\|G_i-G_j\|}{2}\le f_1(P).
\end{equation}

无符合条件的点对时取下界 $0$。设已有某候选点的评分上界为
$U_{\rm best}$，若 $\ell_{\rm pair}(P)>U_{\rm best}+\tau$，
则可排除该点，不予进一步细算。

\subsubsection{第二阶段打分（精评）}

在经由第一阶段的初步筛选后，对于剩余的候选点 $P$ ，用源域的凸外多边形确定所有可能方向的覆盖区间，
再向两侧扩展 $\tau$。若 $P$ 位于该多边形内，取整个圆周。
这样既能处理跨越 $0^\circ$ 的读数，也能包含所有可能正常观测。

将覆盖区间分成若干个连续的细分角度小区间 $I_j=[\beta_j-\eta_j,\beta_j+\eta_j]$，其中 $\beta_j$ 是第 $j$ 个小区间的中心角度，$\eta_j$ 是该区间的半宽。

若满足 $\tau+\eta_j<\pi/2$，则对于任意属于该小区间内的读数 $\beta\in I_j$，其真实的定位区域均有如下包含关系：
\begin{equation}
J(P,\beta)\subseteq
E_0\cap W(P;\beta_j,\tau+\eta_j)\cap\{G:\|G-P\|>5\}.
\end{equation}

为了有效计算最差包围半径 $f_1(P)$，我们采用内外多边形近似来构建其上下界：

对于右侧的区域，构造一个外接多边形近似记为 $K_j^+$，它的最小包围圆半径$\rho(K_j^+)$必然大于真实区域的半径，从而为该小区间 $I_j$ 提供了包围半径的局部上界。

同理，在小区间的真实定位区域 $J(P, \beta_j)$ 内构造一个内接多边形近似记为 $K_j^-$，它提供了局部下界。

综合所有划分的小区间，并结合前文已求得的理论下界，
我们便可以得到评估候选点 $P$ 的全局下界 $L(P)$ 与全局上界 $U(P)$：

\begin{equation}
L(P)=\max\left\{\ell_{\rm pair}(P),r_*,\max_{\text{已采样 }j}\rho(K_j^-)\right\}
\le f_1(P)\le U(P)=\max_j\rho(K_j^+).
\label{eq:q2bounds}
\end{equation}
\\
由于求精确的非线性交点非常耗时，通过这种上下界放缩的机制，我们只需不断细分角度区间，当 $U(P)$ 和 $L(P)$ 足够接近时，即可认为我们以极高的精度逼近了真实的最差包围半径 $f_1(P)$。

注意内外近似须保持包含方向：源域圆弧用连弦构造子集、相邻切线构造超集；
扣除近源圆孔时则相反，内近似扣除外接孔，外近似只扣除内接孔。

对正 $n$ 边形，半径为 $a$ 的内接孔的边心距为 $a\cos(\pi/n)$。
裁剪后，我们需要对各凸片的全部顶点求“最小包围圆”（MEC），得到相应半径与圆心，而这就是我们第二阶段精评打分的绝对依据。

\textbf{最小包围圆（MEC）算法原理与公式：}
给定多边形的顶点集合 $S = \{V_1, V_2, \dots, V_m\}$，最小包围圆问题是寻找一个半径最小的圆，使得集合 $S$ 中的所有点都在该圆内或圆周上。其数学模型为求解如下最优化问题：
\begin{equation}
\begin{aligned}
\min_{c, \rho} \quad & \rho \\
\text{s.t.} \quad & \|V_i - c\| \le \rho, \quad \forall i=1,2,\dots,m
\end{aligned}
\end{equation}

根据计算几何原理，该最优包围圆是唯一存在的，并且它完全由集合 $S$ 中位于其边界上的 $2$ 或 $3$ 个点来唯一确定。

在程序实现中，我们将多边形的顶点离散化后，直接计算其极小极值包围圆的半径 $\rho$，这也是我们在给定测向角 $\beta$ 时所面临的最差误差半径。

我们采用二分上界最大的角度箱策略，直到 $U-L$ 达到指定容差或下界超过淘汰阈值。
程序分别记录收敛、淘汰与预算耗尽状态，并缓存角度箱以供后续续算。
这里的上下界来自集合包含关系，具体实现使用双精度浮点与数值余量。

在圆弧与孔的近似分辨率固定时，极小容差可能无法达到，此时应提高几何分辨率。

\subsubsection{精度优先、兼顾路程的两阶段策略}

为寻找最优第二检测点 $P$，我们设计了“精度优先、兼顾路程”的两阶段搜索策略。
首先在 $E$ 内生成网格点与随机点，利用粗评指标 $\widehat f_1$ 筛选出部分排名靠前且分布较广的点作为搜索起点；接着利用前文下界进行提前淘汰，从这些起点开展带 $E$ 约束的八方向模式搜索。
最后，优先对上界较小的候选点进行精评，并实时检验路程较短的点（精评总数设限以避免全域扫描）。

该策略的理论目标是先最小化最差包围半径 $f_1$，再在允许的微小精度让步 $\varepsilon$ 内最小化路程。其数学规划模型为：
\begin{equation}
\begin{aligned}
\min_{P} \quad & f_2(P) = \|P\| \\
\text{s.t.} \quad & \left\{
\begin{aligned}
& f_1(P) \le m + \varepsilon, \\
& m = \inf_{P'\in E} f_1(P'), \\
& P \in E.
\end{aligned}
\right.
\end{aligned}
\end{equation}
实际搜索得到的是有限个精评点组成的集合 $\mathcal C$。令
\begin{equation*}
\widehat m=\min_{P\in\mathcal C}U(P),\quad
\widehat{\mathcal F}_\varepsilon=
\{P\in\mathcal C:U(P)\le\widehat m+\varepsilon\},\quad
S\in\arg\min_{P\in\widehat{\mathcal F}_\varepsilon}\|P\|.
\end{equation*}

$\mathcal C$ 只包含达到精评容差的点。由此得到相对于当前数值最好结果的优良候选点集，
移动时间为 $\|S\|/5$。

function [D, V, flag, AB] = position_diameter(S, theta)
%POSITION_DIAMETER 问题1：交会定位区域直径（向量化暴力求直径）
%   [D, V, flag, AB] = position_diameter(S, theta)
%
%   输入（两项，均为用户输入）：
%       S     - n×2 矩阵，每行是一个检测点坐标 (x,y)，单位：米
%       theta - n×1 向量，各检测点处测得的示向度（方位角，单位：度，范围 [0,360)）
%
%   输出：
%       D    - 定位区域（凸多边形）的直径，单位：米
%       V    - 定位区域顶点（逆时针排列，m×2 矩阵）
%       flag - 状态：1=区域有界（直径有效），0=区域无界（直径无意义）
%       AB   - 直径两端点（2×2 矩阵），可选输出
%
%   方法（对应问题一的解法）：
%       每个检测点 S_i 确定一个张角 2*tau 的视界楔形
%           W_i = { P : |wrap(arg(P - S_i) - theta_i)| <= tau }
%       定位区域 R = 所有楔形之交，是一个凸多边形；
%       其直径 = 凸多边形顶点对距离的最大值（向量化暴力法，无循环求得）。
tau = 1;        % 测向误差界（度）
M   = 10000;    % 裁剪用包围盒半边长（米），可自行调整
n = size(S, 1);
if ~(n >= 1 && size(S,2) == 2 && numel(theta) == n)
error('输入尺寸不匹配：S 应为 n×2，theta 应为 n×1');
end
% ---- 0. 有界性判定（问题一：最小包围弧 > 2*tau 才有界）----
[flag, arc] = boundedness(theta, tau);
if ~flag
warning('示向度最小包围弧 = %.2f° <= 2*tau = %.0f°，定位区域无界，直径无意义。', arc, 2*tau);
end
% ---- 1. 用包围盒初始化多边形 ----
V = [-M -M; M -M; M M; -M M];
% ---- 2. 逐个楔形裁剪（每个楔形 = 两条半平面 n'*P <= c）----
for i = 1:n
[n1, c1, n2, c2] = wedge_halfplanes(S(i,:), theta(i), tau);
V = clip_halfplane(V, n1, c1);
V = clip_halfplane(V, n2, c2);
if isempty(V)
flag = 0; D = 0; V = []; AB = []; return;
end
end
% ---- 3. 取凸包（去掉共线/重复点，得到规范凸多边形）----
V = convex_hull(V);
% ---- 4. 向量化暴力求直径（顶点对最大距离，无循环）----
[D, AB] = polygon_diameter(V);
% ---- 5. 若区域触及包围盒，说明实际无界 ----
if flag && (max(abs(V(:))) > 0.99 * M)
flag = 0;
warning('区域触及包围盒边界，可能无界，直径结果不可靠。');
end
end
%% ======================= 子函数 =======================
function [n1, c1, n2, c2] = wedge_halfplanes(S, th, tau)
% 楔形 W(S,th,tau) 的两条边界半平面  n'*P <= c
% 边界1：方向角 th-tau 的射线（外法向 n1）
% 边界2：方向角 th+tau 的射线（外法向 n2）
a1 = (th - tau) * pi / 180;
a2 = (th + tau) * pi / 180;
n1 = [sin(a1), -cos(a1)];     % 边界 th-tau 的外法向
c1 = n1 * S(:);
n2 = [-sin(a2), cos(a2)];     % 边界 th+tau 的外法向
c2 = n2 * S(:);
end
function P = clip_halfplane(P, n, c)
% Sutherland-Hodgman 半平面裁剪：保留 n'*p <= c
if isempty(P), return; end
m = size(P, 1);
Q = zeros(0, 2);
for i = 1:m
j  = mod(i, m) + 1;
pi_ = P(i, :);
pj  = P(j, :);
fi = n * pi_' - c;
fj = n * pj'  - c;
if fi <= 0
Q(end+1, :) = pi_;                  %#ok<AGROW>
end
if (fi <= 0) ~= (fj <= 0)
t = fi / (fi - fj);
Q(end+1, :) = pi_ + t * (pj - pi_); %#ok<AGROW>
end
end
P = Q;
end
function H = convex_hull(P)
% 单调链凸包（返回逆时针顶点）
if size(P, 1) <= 2, H = P; return; end
P = unique(P, 'rows');
P = sortrows(P, [1 2]);
lower = zeros(0, 2);
for i = 1:size(P, 1)
while size(lower, 1) >= 2 && ...
cross2(lower(end,:) - lower(end-1,:), P(i,:) - lower(end-1,:)) <= 0
lower(end, :) = [];
end
lower(end+1, :) = P(i, :);             %#ok<AGROW>
end
upper = zeros(0, 2);
for i = size(P, 1):-1:1
while size(upper, 1) >= 2 && ...
cross2(upper(end,:) - upper(end-1,:), P(i,:) - upper(end-1,:)) <= 0
upper(end, :) = [];
end
upper(end+1, :) = P(i, :);             %#ok<AGROW>
end
H = [lower(1:end-1, :); upper(1:end-1, :)];
end
function [D, AB] = polygon_diameter(H)
%POLYGON_DIAMETER 向量化暴力法求凸多边形直径（无循环）
%   输入 H: 逆时针凸多边形顶点 (m×2)
%   输出 D: 直径（米）；AB: 直径两端点 (2×2)
%
%   原理：凸多边形直径 = 顶点对距离的最大值（问题一定理）。
%   顶点数 m 很小，直接用隐式扩展一次性算出所有顶点对距离，全程无循环。
m = size(H, 1);
if m < 2
D = 0; AB = zeros(0, 2); return;
end
% 所有顶点对的坐标差：m×m（利用 MATLAB 隐式扩展，无需双重循环）
dx = H(:,1) - H(:,1).';   % x_i - x_j
dy = H(:,2) - H(:,2).';   % y_i - y_j
D2 = dx.^2 + dy.^2;       % 所有顶点对平方距离
[D2max, idx] = max(D2(:));          % 最大平方距离及其线性索引
[i, j] = ind2sub([m m], idx);       % 对应顶点对
D  = sqrt(D2max);
AB = [H(i,:); H(j,:)];
end
function [flag, arc] = boundedness(theta, tau)
% 有界性判定：最小包围弧 > 2*tau 则定位区域有界
th = sort(mod(theta(:), 360));
n = numel(th);
if n < 2
flag = false; arc = 360; return;
end
gmax = 0;
for i = 1:n
gap = mod(th(mod(i,n)+1) - th(i), 360);
gmax = max(gmax, gap);
end
if gmax == 0
arc = 0;     % 所有示向度相同 -> 退化为单锥，无界
else
arc = 360 - gmax;
end
flag = arc > 2*tau;
end
function z = cross2(a, b)
z = a(1)*b(2) - a(2)*b(1);
end

function D = diameter_many(V)
%DIAMETER_MANY 批量计算多个凸多边形的直径（向量化，R2016b+ 隐式扩展）
%   D = diameter_many(V)
%
%   输入 V: 1×P cell 数组，V{p} 为第 p 个多边形的顶点（m_p×2，逆时针）
%   输出 D: P×1 各多边形的直径（米）
%
%   原理：凸多边形直径 = 顶点对最大距离。
%   顶点少、多边形多时，瓶颈是逐多边形循环；本函数把所有多边形堆成三维数组，
%   用隐式扩展一次性算完所有顶点对距离，全程向量化（仅堆叠一步有循环）。

    P    = numel(V);
    mmax = max(cellfun(@(v) size(v,1), V));

    % 堆成 mmax×2×P 三维数组，缺省顶点用 NaN 填充
    X = NaN(mmax, 2, P);
    for p = 1:P
        X(1:size(V{p},1), :, p) = V{p};
    end

    % 所有顶点对 (i,j) 的坐标差：mmax×mmax×P（隐式扩展，无双重循环）
    dx = X(:,1,:) - permute(X(:,1,:), [2 1 3]);   % x_i - x_j
    dy = X(:,2,:) - permute(X(:,2,:), [2 1 3]);   % y_i - y_j
    D2 = dx.^2 + dy.^2;                           % 所有顶点对平方距离

    D2(isnan(D2)) = 0;        % NaN（补位处）置 0，不影响取最大值

    D = sqrt(max(D2, [], [1 2]));   % 1×1×P
    D = squeeze(D);                 % P×1
end

function problem2_discrete_sweep()
% PROBLEM2_DISCRETE_SWEEP 基于 Kershner 定理和集合覆盖规划离散检测点及 TSP 最短路
    
    R = 56.5; % 最坏误差半径
    r = 20;   % 探测半径
    v = 5;    % 移动速度 5m/s (假设)
    t_measure = 5; % 每次测量耗时 5s
    
    fprintf('=== 问题2：离散检测点全覆盖路径规划 ===\n');
    fprintf('误差半径 R = %.1f m, 探测半径 r = %.1f m\n', R, r);
    
    % 1. 离散化被覆盖区域 D(0, R)
    [X, Y] = meshgrid(linspace(-R, R, 150));
    mask = X.^2 + Y.^2 <= R^2;
    Px = X(mask); Py = Y(mask);
    N_target = length(Px);
    
    % 2. 基于 Kershner 正六边形密铺定理生成候选中心
    dx = r * sqrt(3) / 2 * 0.8; 
    dy = r * 3/4 * 0.8;
    [CX, CY] = meshgrid(-R-r:dx:R+r, -R-r:dy:R+r);
    shift = repmat([0, dx/2], size(CX,1), ceil(size(CX,2)/2));
    shift = shift(:, 1:size(CX,2));
    CX = CX + shift;
    
    c_mask = CX.^2 + CY.^2 <= (R+r/4)^2; 
    Cx = CX(c_mask); Cy = CY(c_mask);
    N_cand = length(Cx);
    
    % 3. 构造覆盖矩阵 A
    A = zeros(N_target, N_cand);
    for j = 1:N_cand
        dist2 = (Px - Cx(j)).^2 + (Py - Cy(j)).^2;
        A(:, j) = (dist2 <= r^2);
    end
    
    % 4. 求解最小集合覆盖问题 (Set Cover ILP)
    f = ones(N_cand, 1);
    intcon = 1:N_cand;
    b = -ones(N_target, 1);
    
    options = optimoptions('intlinprog', 'Display', 'off');
    [x_opt, fval, exitflag] = intlinprog(f, intcon, -A, b, [], [], zeros(N_cand,1), ones(N_cand,1), options);
    
    if exitflag > 0
        N_opt = round(fval);
        sel = x_opt > 0.5;
        Sel_X = Cx(sel); Sel_Y = Cy(sel);
        fprintf('成功求得最小检测点数量: %d 个\n', N_opt);
        
        pts = [Sel_X, Sel_Y];
        
        % 5. 求解 TSP 遍历最短路径 (贪心 + 2-opt)
        start_pt = [0, 0];
        [tour_idx, tour_dist] = solve_tsp(pts, start_pt);
        
        total_time = N_opt * t_measure + tour_dist / v;
        fprintf('TSP 最短行走距离: %.2f m\n', tour_dist);
        fprintf('预估总耗时 (含 %d 次停机检测): %.2f s\n', N_opt, total_time);
        
        % 6. 可视化绘图
        plot_discrete_coverage(R, r, pts, tour_idx, start_pt, tour_dist, N_opt);
    else
        fprintf('ILP 求解失败，无法找到全覆盖子集。\n');
    end
end

function [best_tour, best_dist] = solve_tsp(pts, start_pt)
    N = size(pts, 1);
    unvisited = 1:N;
    curr = start_pt;
    tour = [];
    dist = 0;
    
    % 贪心初始化
    while ~isempty(unvisited)
        [~, idx] = min(sum((pts(unvisited,:) - curr).^2, 2));
        next = unvisited(idx);
        dist = dist + norm(pts(next,:) - curr);
        tour(end+1) = next;
        curr = pts(next,:);
        unvisited(idx) = [];
    end
    
    % 简单的 2-opt 优化
    improved = true;
    while improved
        improved = false;
        for i = 1:N-2
            for j = i+2:N
                new_tour = tour;
                new_tour(i+1:j) = wrev(tour(i+1:j)); % 逆序子路径
                new_dist = calc_tour_dist(new_tour, pts, start_pt);
                if new_dist < dist - 1e-5
                    tour = new_tour;
                    dist = new_dist;
                    improved = true;
                end
            end
        end
    end
    best_tour = tour;
    best_dist = dist;
end

function rev = wrev(arr)
    rev = arr(end:-1:1);
end

function d = calc_tour_dist(tour, pts, start_pt)
    d = norm(pts(tour(1),:) - start_pt);
    for i = 1:length(tour)-1
        d = d + norm(pts(tour(i+1),:) - pts(tour(i),:));
    end
end

function [fval, pts] = optimize_sweep(R, r, verbose)
    % 生成高密度测试点
    [X, Y] = meshgrid(linspace(-R, R, 150));
    mask = X.^2 + Y.^2 <= R^2;
    Px = X(mask);
    Py = Y(mask);
    
    options = optimoptions('fmincon', 'Display', 'none', 'Algorithm', 'sqp', ...
        'MaxFunctionEvaluations', 2000, 'StepTolerance', 1e-6);
    
    % 根据 R 动态选择扫线拓扑
    if R <= 40
        % 2 趟扫线 (U型拓扑)
        x0 = [R, R/2];
        lb = [0, 0];
        ub = [R, R];
        obj = @(v) 4*v(1) + 2*v(2);
        nonlcon = @(v) constraint_2sweep(v, Px, Py, r);
    else
        % 3 趟扫线 (S型/割草机拓扑)
        x0 = [R*0.8, R*0.6, R*0.8];
        lb = [0, 0, 0];
        ub = [R, R, R];
        obj = @(v) 4*v(1) + 2*v(3) + 2*sqrt((v(3)-v(1))^2 + v(2)^2);
        nonlcon = @(v) constraint_3sweep(v, Px, Py, r);
    end
    
    if verbose, fprintf('开始寻优 R = %.1f m ...\n', R); end
    [v_opt, fval] = fmincon(obj, x0, [], [], [], [], lb, ub, nonlcon, options);
    
    % 重建节点
    if R <= 40
        x1 = v_opt(1); y1 = v_opt(2);
        pts = [x1, y1; -x1, y1; -x1, -y1; x1, -y1];
    else
        x1 = v_opt(1); y1 = v_opt(2); x2 = v_opt(3);
        pts = [x1, y1; -x1, y1; -x2, 0; x2, 0; x1, -y1; -x1, -y1];
    end
end

function [c, ceq] = constraint_2sweep(v, Px, Py, r)
    x1 = v(1); y1 = v(2); r2 = r^2;
    d1 = dist2seg(Px, Py, x1, y1, -x1, y1);
    d2 = dist2seg(Px, Py, -x1, y1, -x1, -y1);
    d3 = dist2seg(Px, Py, -x1, -y1, x1, -y1);
    min_d = min(cat(2, d1, d2, d3), [], 2);
    c = min_d - r2 + 1e-4; 
    ceq = [];
end

function [c, ceq] = constraint_3sweep(v, Px, Py, r)
    x1 = v(1); y1 = v(2); x2 = v(3); r2 = r^2;
    d1 = dist2seg(Px, Py, x1, y1, -x1, y1);
    d2 = dist2seg(Px, Py, -x1, y1, -x2, 0);
    d3 = dist2seg(Px, Py, -x2, 0, x2, 0);
    d4 = dist2seg(Px, Py, x2, 0, x1, -y1);
    d5 = dist2seg(Px, Py, x1, -y1, -x1, -y1);
    min_d = min(cat(2, d1, d2, d3, d4, d5), [], 2);
    c = min_d - r2 + 1e-4; 
    ceq = [];
end

function d2 = dist2seg(px, py, ax, ay, bx, by)
    dx = bx - ax; dy = by - ay; l2 = dx^2 + dy^2;
    if l2 == 0
        d2 = (px - ax).^2 + (py - ay).^2; return;
    end
    t = max(0, min(1, ((px - ax)*dx + (py - ay)*dy) / l2));
    projx = ax + t * dx; projy = ay + t * dy;
    d2 = (px - projx).^2 + (py - projy).^2;
end

function [metrics,errText]=runCase(solver,channels,xy,radius,noiseSeed,scenario)
% 单案例封闭模拟器；真实数据不进入solver，仅通过四种接口结果反馈。
n=numel(channels); live=true(1,n); p=[0;0]; ch=1; t=0; parts=zeros(1,4);
clearTimes=[]; errText=""; result=struct(); start=tic;
try
    result=solver(@simulator);
catch err
    errText=string(err.message);
end
count=sum(~live); average=t/max(1,count); if count==0, average=inf; end
complete=~any(live) && isfield(result,'complete') && result.complete;
tail=nan; if ~isempty(clearTimes), tail=t-max(clearTimes); end
anchorRadius=nan;
if isfield(result,'anchorRadius'), anchorRadius=result.anchorRadius; end
assert(abs(t-sum(parts))<1e-6,'模拟计时分项不守恒。');
metrics=[count,t,average,toc(start),complete,parts,tail,anchorRadius];

    function z=simulator(path,request)
        z=struct('accepted',true,'virtual_time_s',t);
        if strcmp(path,'/enter'), z.remaining_real_duration_s=1200; return; end
        if strcmp(path,'/exit'), z.exit_reason='user_exit'; return; end
        q=[request.position.x;request.position.y]; k=request.channel;
        dt=norm(q-p)/5; parts(1)=parts(1)+dt; t=t+dt; p=q;
        j=find(channels==k & live,1); d=inf;
        if ~isempty(j), d=norm(xy(:,j)-p); end
        if strcmp(path,'/measure')
            sw=double(ch~=k); ch=k; t=t+sw+5;
            parts(2)=parts(2)+sw; parts(3)=parts(3)+5;
            if isempty(j)||d>radius(j), z.measure_result='no_signal';
            elseif d<=5, z.measure_result='near';
            else
                % 确定性伪随机误差场：同一案例、频道、地点给两个算法相同误差。
                w=sin(q(1)*12.9898+q(2)*78.233+k*37.719+noiseSeed*.013)*43758.5453;
                e=2*(w-floor(w))-1;
                if strcmp(scenario,'extreme'), e=sign(e); end
                v=xy(:,j)-p; z.measure_result='direction';
                z.svd_deg=mod(round(atan2d(v(2),v(1))+e,2),360);
            end
        else
            ok=d<=20; dt=3+2*ok; t=t+dt; parts(4)=parts(4)+dt;
            if ok
                live(j)=false; z.clear_result='success'; clearTimes(end+1)=t;
            else
                z.clear_result='no_target_in_range';
            end
        end
        z.virtual_time_s=t;
    end
end

    % 扫描中顺便更新已知源的交会区域，共享一次移动带来的观测机会。
    if any(newlyCovered) && (sum(newlyCovered)*h^2>=8e5 || isempty(pending))
        order = [channel,setdiff(1:20,channel,'stable')];
        for k = order
            if ~done(k) && (~known(k)||radii(k)>60), observe(pos,k); end
        end

                       unseen(2,:)'-anchors(2,:))<=coverR,1);

    % 最近邻给初始路线，2-opt 只做路段反转；每完成一项再更新这条路线。
    tasks = [centers(:,pending),anchors(:,useful)];
    tour = zeros(1,size(tasks,2)); left = 1:size(tasks,2); q = pos;
    for i = 1:numel(tour)
        [~,j] = min(vecnorm(tasks(:,left)-q));
        tour(i)=left(j); q=tasks(:,left(j)); left(j)=[];
    end
    improved = true;
    while improved
        improved = false;
        for i = 1:numel(tour)-1
            for j = i+1:numel(tour)
                route=[pos,tasks(:,tour)];
                old=norm(route(:,i)-route(:,i+1));
                new=norm(route(:,i)-route(:,j+1));
                if j<numel(tour)
                    old=old+norm(route(:,j+1)-route(:,j+2));
                    new=new+norm(route(:,i+1)-route(:,j+2));

            if clearAt(c,k), break; end

        else

            u = c-pos; if norm(u)<1e-9, u = [1;0]; end

function out = problem4_solver(robotId, baseUrl)
% 问题四基础款：双环稳健搜索 + 成对侧向交会，兼容全向和180度定向源。
% 官方模拟器：out = problem4_solver('你们的参赛队号');
% 本地检验：problem4_monte_carlo(100,20260912,'uniform');
% 直接复用问题一的 diameter_many 和问题二的半平面、最小包围圆算法。
if nargin<1, error('请传入参赛队号；本地测试请运行 problem4_monte_carlo。'); end
if nargin<2, baseUrl='http://127.0.0.1:2026'; end
root=fileparts(mfilename('fullpath'));
addpath(fullfile(root,'问题1_交会定位'));
addpath(genpath(fullfile(root,'问题2_第二检测点选择')));
cfg=config_problem2();
local=isa(robotId,'function_handle');
if local, transport=robotId; robotId='local'; end
opt=weboptions('MediaType','application/json','Timeout',5);
pos=[0;0]; channel=1; vt=0; serial=0; limit=inf; clock0=tic;
inLocal=false; globalDistance=0; localDistance=0;
known=false(1,20); done=known; regions=cell(1,20);
centers=nan(2,20); radii=inf(1,20); obsCount=zeros(1,20);
lastPos=nan(2,20); lastTheta=nan(1,20);
firstPos=nan(2,20); firstTheta=nan(1,20);
discovered=nan(1,20); cleared=nan(1,20); history=cell(0,3);
fallbackCount=0; raySweepCount=0;

% 搜索覆盖证书：外环正十二边形内切圆半径
% 1865*cos(15度)=1801.46>1800；内外环错开15度。
% 原点、内环和外环的三角剖分最大边长约979 m，小于最小接收半径1000 m。
% 任意源位于某个小三角形内；任意过该源的180度半平面至少含一个顶点，
% 所以不论定向源朝向如何，至少有一个距离不超过1000 m的搜索站能收到信号。
a=(0:11)*pi/6;
stations=[[0;0],950*[cos(a);sin(a)],1865*[cos(a+pi/12);sin(a+pi/12)]];
visited=false(1,size(stations,2));
ang=(0:71)*2*pi/72;
domain=1800/cos(pi/72)*[cos(ang);sin(ang)]; % 圆域的保守外接多边形

reply=act('/enter'); limit=reply.remaining_real_duration_s;
reason='search_complete';
while true
    if toc(clock0)>limit-10, reason='real_time_limit'; break; end
    if sum(done)==16, reason='all_16_cleared'; break; end
    left=find(~visited);
    pending=find(known & ~done);
    if isempty(left)&&isempty(pending), break; end

    % 把待清除源与剩余搜索站放入同一条开放路线；目标只有在顺路成为
    % 下一节点时才追踪，后续搜索站也可在此前免费补充新的方位线。
    tasks=[centers(:,pending),stations(:,left)];
    tour=zeros(1,size(tasks,2)); pool=1:size(tasks,2); q=pos;
    for routeStep=1:numel(tour)
        [~,pick]=min(vecnorm(tasks(:,pool)-q));
        tour(routeStep)=pool(pick); q=tasks(:,pool(pick)); pool(pick)=[];
    end
    improved=true;
    while improved
        improved=false; route=[pos,tasks(:,tour)];
        for swapStart=1:numel(tour)-1
            for swapEnd=swapStart+1:numel(tour)
                old=norm(route(:,swapStart)-route(:,swapStart+1));
                new=norm(route(:,swapStart)-route(:,swapEnd+1));
                if swapEnd<numel(tour)
                    old=old+norm(route(:,swapEnd+1)-route(:,swapEnd+2));
                    new=new+norm(route(:,swapStart+1)-route(:,swapEnd+2));
                end
                if new<old-1e-7
                    tour(swapStart:swapEnd)=fliplr(tour(swapStart:swapEnd)); improved=true;
                    route=[pos,tasks(:,tour)];
                end
            end
        end
    end
    next=tour(1);
    if next<=numel(pending)
        k=pending(next); inLocal=true; localize(k); inLocal=false;
        continue;
    end
    stationId=left(next-numel(pending));
    q=stations(:,stationId); visited(stationId)=true;

    % 未发现频道继续全查；已发现频道最多利用搜索站补到六条方位线，
    % 此后等待路线中的追踪节点，避免重复测量同一频道。
    list=find(~done & (~known | obsCount<6));
    order=[channel,setdiff(list,channel,'stable')];
    if ~ismember(channel,list), order=list; end
    for k=order
        observe(q,k);
        if sum(done)==16, break; end
    end

end
if toc(clock0)<=limit-5, act('/exit'); end
out=struct('cleared',sum(done),'totalTime',vt,'averageTime',vt/max(1,sum(done)), ...
    'complete',(all(visited)||sum(done)==16) && all(~known|done), ...
    'reason',reason,'runtime',toc(clock0),'discoveryTime',discovered, ...
    'clearTime',cleared,'observations',obsCount,'finalRadius',radii,'history',{history}, ...
    'stationsVisited',sum(visited),'stationCount',size(stations,2), ...
    'fallbackCount',fallbackCount,'raySweepCount',raySweepCount, ...
    'globalDistance',globalDistance,'localDistance',localDistance);
if ~local
    stamp=char(datetime('now','Format','yyyyMMdd_HHmmss'));
    save(fullfile(root,['problem4_run_' stamp '.mat']),'out');
    fprintf('问题四基础款：清除%d个，总时间%.2f s，平均%.2f s，完整排查=%d\n', ...
        out.cleared,out.totalTime,out.averageTime,out.complete);
end

    function localize(k)
        % 沿最近测向线向前推进。两探测点关于测向线对称，侧移量超过
        % 490*tan(1.005度)，所以真实射线穿过两点之间的线段；只要源仍在
        % 前方，180度发射半平面至少包含其中一点，且两点均在接收半径内。
        for round=1:5
            if done(k), return; end
            if radii(k)<=20 && clearAt(centers(:,k),k), return; end
            q0=lastPos(:,k); th=lastTheta(k);
            if any(~isfinite(q0))||~isfinite(th), break; end
            U=min(1500,max(vecnorm(regions{k}-q0)));
            if U<=600, raySweep(k,q0,th,U); return; end
            u=[cos(th);sin(th)]; v=[-u(2);u(1)];
            advance=min(490,0.6*U); side=advance*tan(deg2rad(1.005))+3;
            probes=[q0+advance*u+side*v,q0+advance*u-side*v];
            if norm(probes(:,2)-pos)<norm(probes(:,1)-pos), probes=fliplr(probes); end
            hit=observe(probes(:,1),k);
            if ~done(k)&&~hit, hit=observe(probes(:,2),k); end
            if done(k), return; end
            if ~hit
                % 成对无信号时，源必在推进截面之前；无信号在这里作为
                % “一对互补实验”的联合结论使用，而非单点排除。
                raySweep(k,q0,th,advance/cos(deg2rad(1.005))+1); return;
            end
            if clearAt(lastPos(:,k),k), return; end
        end
        if done(k), return; end

        % 兜底只使用第一次有效测向：真源在长1500 m、半宽26.32 m的窄带内。
        % 28 m方格的覆盖半径为19.80 m，小于20 m清除半径，因此必能清除。
        fallbackCount=fallbackCount+1; u=[cos(firstTheta(k));sin(firstTheta(k))];
        v=[-u(2);u(1)]; xs=0:28:1512; ys=[-42,-14,14,42];
        % 四种蛇形起点中选离当前位置最近者，避免无意义折返。
        paths=cell(1,4); d0=inf(1,4); c=0;
        for flipY=0:1
            yy=ys; if flipY, yy=fliplr(yy); end
            for flipX=0:1
                c=c+1; P=zeros(2,numel(xs)*numel(yy)); t=0;
                for r=1:numel(yy)
                    xx=xs; if mod(r+flipX,2)==0, xx=fliplr(xx); end
                    Q=firstPos(:,k)+u*xx+v*(yy(r)*ones(size(xx)));
                    P(:,t+(1:numel(xx)))=Q; t=t+numel(xx);
                end
                paths{c}=P; d0(c)=norm(P(:,1)-pos);
            end
        end
        [~,c]=min(d0); P=paths{c};
        for fallbackPoint=1:size(P,2)
            if clearAt(P(:,fallbackPoint),k), return; end
        end
        error('光学窄带兜底失败：请检查测向误差或模拟器规则。');
    end

    function raySweep(k,q0,th,U)
        % 已知源在长度U的单次测向误差带内。当U<=600 m时横向误差小于
        % 10.53 m；按清除圆余下的弦长设置纵向间距，可用一条直线完全覆盖。
        raySweepCount=raySweepCount+1; epsA=deg2rad(1.005);
        halfWidth=U*sin(epsA); assert(halfWidth<20,'测向带过宽，不能单线覆盖。');
        step=1.98*sqrt(20^2-halfWidth^2);
        xs=step/2:step:U+step/2;
        u=[cos(th);sin(th)]; P=q0+u*xs;
        if norm(P(:,end)-pos)<norm(P(:,1)-pos), P=fliplr(P); end
        for sweepPoint=1:size(P,2)
            if clearAt(P(:,sweepPoint),k), return; end
        end
        error('测向带直线覆盖失败：请检查误差上界或距离上界。');
    end

    function hit=observe(q,k)
        % no_signal 可能由距离、朝向或空频道造成，故不据此裁剪位置区域。
        z=act('/measure',q,k); hit=~strcmp(z.measure_result,'no_signal');
        if ~hit, return; end
        if ~known(k)
            known(k)=true; discovered(k)=vt; regions{k}=domain;
        end
        if strcmp(z.measure_result,'near')
            assert(clearAt(q,k),'near 后光学清除失败。'); return;
        end
        th=deg2rad(z.svd_deg); obsCount(k)=obsCount(k)+1;
        lastPos(:,k)=q; lastTheta(k)=th;
        if obsCount(k)==1, firstPos(:,k)=q; firstTheta(k)=th; end
        [n1,b1,n2,b2]=wedge_planes(q,th,deg2rad(1.005));
        V=clip_halfplane(regions{k},n1,b1+1e-7);
        V=clip_halfplane(V,n2,b2+1e-7);
        u=[cos(th);sin(th)]; V=clip_halfplane(V,u,u'*q+1500+1e-7);
        assert(~isempty(V),'交会区域为空：观测与误差模型不相容。');
        regions{k}=V; D=diameter_many({V'});
        if D<=20, c=V(:,1); r=D;
        else, [c,r]=welzl_mec(V,cfg); end
        centers(:,k)=c; radii(k)=max(r,max(vecnorm(V-c)));
    end

    function success=clearAt(q,k)
        z=act('/clear',q,k); success=strcmp(z.clear_result,'success');
        if success, done(k)=true; cleared(k)=vt; end
    end

    function z=act(path,q,k)
        % 新动作使用新ID；网络故障只重试完全相同的请求和ID。
        if ~strcmp(path,'/exit')&&toc(clock0)>limit-5
            error('现实时间不足，停止发送新动作。');
        end
        serial=serial+1;
        request=struct('arena_id','default','robot_id',robotId, ...
            'request_id',sprintf('p4-%d',serial));
        if nargin>1
            request.position=struct('x',q(1),'y',q(2)); request.channel=k;
        end
        for attempt=1:3
            try
                if local, z=transport(path,request);
                else, z=webwrite([baseUrl path],request,opt); end
                break;
            catch err
                if attempt==3, rethrow(err); end
            end
        end

function out = problem4_solver_split(robotId, baseUrl)
% 问题四分流优化版：信号稳定时沿用问题三全向定位，失联后转定向追踪。
% 官方模拟器：out = problem4_solver_split('你们的参赛队号');
% 配对检验：problem4_compare_split_monte_carlo(100,20260912,'uniform');
% 与基础款保持同一主结构；标有“分流改动”的部分是本版新增逻辑。
if nargin<1, error('请传入参赛队号；本地测试请运行配对蒙特卡洛程序。'); end
if nargin<2, baseUrl='http://127.0.0.1:2026'; end
root=fileparts(mfilename('fullpath'));
addpath(fullfile(root,'问题1_交会定位'));
addpath(genpath(fullfile(root,'问题2_第二检测点选择')));
cfg=config_problem2();
local=isa(robotId,'function_handle');
if local, transport=robotId; robotId='local'; end
opt=weboptions('MediaType','application/json','Timeout',5);
pos=[0;0]; channel=1; vt=0; serial=0; limit=inf; clock0=tic;
inLocal=false; globalDistance=0; localDistance=0;
known=false(1,20); done=known; regions=cell(1,20);
centers=nan(2,20); radii=inf(1,20); obsCount=zeros(1,20);
lastPos=nan(2,20); lastTheta=nan(1,20);
firstPos=nan(2,20); firstTheta=nan(1,20);
discovered=nan(1,20); cleared=nan(1,20); history=cell(0,3);
fallbackCount=0; raySweepCount=0;

% 分流改动：mode=1 表示仍按全向源处理，mode=2 表示转入定向稳健追踪。
mode=zeros(1,20); certifiedDirectional=false(1,20); omniRefineCount=0;

% 与基础款完全相同的25点确定性覆盖证书，不淘汰任何未发现频道。
a=(0:11)*pi/6;
stations=[[0;0],950*[cos(a);sin(a)],1865*[cos(a+pi/12);sin(a+pi/12)]];
visited=false(1,size(stations,2));
ang=(0:71)*2*pi/72;
domain=1800/cos(pi/72)*[cos(ang);sin(ang)];

reply=act('/enter'); limit=reply.remaining_real_duration_s;
reason='search_complete';
while true
    if toc(clock0)>limit-10, reason='real_time_limit'; break; end
    if sum(done)==16, reason='all_16_cleared'; break; end
    left=find(~visited); pending=find(known & ~done);
    if isempty(left)&&isempty(pending), break; end

    % 与问题三/基础款一致：待清除源和剩余搜索站统一做开放路径排序。
    tasks=[centers(:,pending),stations(:,left)];
    tour=zeros(1,size(tasks,2)); pool=1:size(tasks,2); q=pos;
    for routeStep=1:numel(tour)
        [~,pick]=min(vecnorm(tasks(:,pool)-q));
        tour(routeStep)=pool(pick); q=tasks(:,pool(pick)); pool(pick)=[];
    end
    improved=true;
    while improved
        improved=false; route=[pos,tasks(:,tour)];
        for swapStart=1:numel(tour)-1
            for swapEnd=swapStart+1:numel(tour)
                old=norm(route(:,swapStart)-route(:,swapStart+1));
                new=norm(route(:,swapStart)-route(:,swapEnd+1));
                if swapEnd<numel(tour)
                    old=old+norm(route(:,swapEnd+1)-route(:,swapEnd+2));
                    new=new+norm(route(:,swapStart+1)-route(:,swapEnd+2));
                end
                if new<old-1e-7
                    tour(swapStart:swapEnd)=fliplr(tour(swapStart:swapEnd));
                    improved=true; route=[pos,tasks(:,tour)];
                end
            end
        end
    end
    next=tour(1);
    if next<=numel(pending)
        k=pending(next); inLocal=true; localize(k); inLocal=false; continue;
    end
    stationId=left(next-numel(pending)); q=stations(:,stationId); visited(stationId)=true;

    % 全局扫描条件与基础款相同，保留所有顺路获得方位线的机会。
    list=find(~done & (~known | obsCount<6));
    order=[channel,setdiff(list,channel,'stable')];
    if ~ismember(channel,list), order=list; end
    for k=order
        observe(q,k,false);
        if sum(done)==16, break; end
    end
end
if toc(clock0)<=limit-5, act('/exit'); end
out=struct('cleared',sum(done),'totalTime',vt,'averageTime',vt/max(1,sum(done)), ...
    'complete',(all(visited)||sum(done)==16) && all(~known|done), ...
    'reason',reason,'runtime',toc(clock0),'discoveryTime',discovered, ...
    'clearTime',cleared,'observations',obsCount,'finalRadius',radii,'history',{history}, ...
    'stationsVisited',sum(visited),'stationCount',size(stations,2), ...
    'fallbackCount',fallbackCount,'raySweepCount',raySweepCount, ...
    'globalDistance',globalDistance,'localDistance',localDistance, ...
    'directionalModeCount',sum(mode==2),'certifiedDirectionalCount',sum(certifiedDirectional), ...
    'p2Tests',omniRefineCount);
if ~local
    stamp=char(datetime('now','Format','yyyyMMdd_HHmmss'));
    save(fullfile(root,['problem4_split_run_' stamp '.mat']),'out');
    fprintf('问题四分流版：清除%d个，总时间%.2f s，平均%.2f s，完整排查=%d\n', ...
        out.cleared,out.totalTime,out.averageTime,out.complete);
end

    function localize(k)
        if done(k), return; end
        if radii(k)<=20 && clearAt(centers(:,k),k), return; end

        % 分流改动：尚未出现过失联时，先假设为全向源，直接复用问题三
        % “区域中心+小幅侧移”的定位形式；点位落在1000 m保证区时，
        % 一旦无信号便可严格确认定向，并立即退出本段。
        if mode(k)==1 && radii(k)<=150
            for omniStep=1:2
                if done(k)||mode(k)==2, break; end
                c=centers(:,k); r=radii(k);
                if r<=60
                    if clearAt(c,k), return; end
                    hit=observe(pos,k,true);
                else
                    u=c-pos; if norm(u)<1e-9, u=[1;0]; end
                    u=u/norm(u); side=min(80,r/2);
                    q=c+side*[-u(2);u(1)];
                    hit=observe(q,k,r+side<=1000);
                end
                omniRefineCount=omniRefineCount+1;
                if ~hit, break; end
                if radii(k)<=20 && clearAt(centers(:,k),k), return; end
            end
        end
        if done(k), return; end

        % 定向稳健段沿用基础款形式：在测向线两侧成对前探。
        for round=1:5
            if done(k), return; end
            if radii(k)<=20 && clearAt(centers(:,k),k), return; end
            q0=lastPos(:,k); th=lastTheta(k);
            if any(~isfinite(q0))||~isfinite(th), break; end
            U=min(1500,max(vecnorm(regions{k}-q0)));
            if U<=600, raySweep(k,q0,th,U); return; end
            u=[cos(th);sin(th)]; v=[-u(2);u(1)];
            advance=min(490,0.6*U); side=advance*tan(deg2rad(1.005))+3;
            probes=[q0+advance*u+side*v,q0+advance*u-side*v];
            if norm(probes(:,2)-pos)<norm(probes(:,1)-pos), probes=fliplr(probes); end
            hit=observe(probes(:,1),k,false);
            if ~done(k)&&~hit, hit=observe(probes(:,2),k,false); end
            if done(k), return; end
            if ~hit
                mode(k)=2;
                raySweep(k,q0,th,advance/cos(deg2rad(1.005))+1); return;
            end
            if clearAt(lastPos(:,k),k), return; end
        end
        if done(k), return; end

        fallbackCount=fallbackCount+1;
        u=[cos(firstTheta(k));sin(firstTheta(k))]; v=[-u(2);u(1)];
        xs=0:28:1512; ys=[-42,-14,14,42];
        paths=cell(1,4); d0=inf(1,4); c=0;
        for flipY=0:1
            yy=ys; if flipY, yy=fliplr(yy); end
            for flipX=0:1
                c=c+1; P=zeros(2,numel(xs)*numel(yy)); t=0;
                for r=1:numel(yy)
                    xx=xs; if mod(r+flipX,2)==0, xx=fliplr(xx); end
                    Q=firstPos(:,k)+u*xx+v*(yy(r)*ones(size(xx)));
                    P(:,t+(1:numel(xx)))=Q; t=t+numel(xx);
                end
                paths{c}=P; d0(c)=norm(P(:,1)-pos);
            end
        end
        [~,c]=min(d0); P=paths{c};
        for fallbackPoint=1:size(P,2)
            if clearAt(P(:,fallbackPoint),k), return; end
        end
        error('光学窄带兜底失败：请检查测向误差或模拟器规则。');
    end

    function raySweep(k,q0,th,U)
        raySweepCount=raySweepCount+1; epsA=deg2rad(1.005);
        halfWidth=U*sin(epsA); assert(halfWidth<20,'测向带过宽，不能单线覆盖。');
        step=1.98*sqrt(20^2-halfWidth^2);
        xs=step/2:step:U+step/2; u=[cos(th);sin(th)]; P=q0+u*xs;
        if norm(P(:,end)-pos)<norm(P(:,1)-pos), P=fliplr(P); end
        for sweepPoint=1:size(P,2)
            if clearAt(P(:,sweepPoint),k), return; end
        end
        error('测向带直线覆盖失败：请检查误差上界或距离上界。');
    end

    function hit=observe(q,k,rangeCertified)
        if known(k) && ~rangeCertified, rangeCertified=rangeGuaranteed(q,k); end
        z=act('/measure',q,k); hit=~strcmp(z.measure_result,'no_signal');
        if ~hit
            if known(k) && mode(k)==1
                % 用户提出的“先全向、出现时有时无再按定向处理”。普通
                % 失联只改变求解分支；保证在接收距离内时还可严格确认定向。
                mode(k)=2;
                if rangeCertified, certifiedDirectional(k)=true; end
            end
            return;
        end
        if ~known(k)
            known(k)=true; mode(k)=1; discovered(k)=vt; regions{k}=domain;
        end
        if strcmp(z.measure_result,'near')
            assert(clearAt(q,k),'near 后光学清除失败。'); return;
        end
        th=deg2rad(z.svd_deg); obsCount(k)=obsCount(k)+1;
        lastPos(:,k)=q; lastTheta(k)=th;
        if obsCount(k)==1, firstPos(:,k)=q; firstTheta(k)=th; end
        [n1,b1,n2,b2]=wedge_planes(q,th,deg2rad(1.005));
        V=clip_halfplane(regions{k},n1,b1+1e-7);
        V=clip_halfplane(V,n2,b2+1e-7);
        u=[cos(th);sin(th)]; V=clip_halfplane(V,u,u'*q+1500+1e-7);
        assert(~isempty(V),'交会区域为空：观测与误差模型不相容。');
        regions{k}=V; D=diameter_many({V'});
        if D<=20, c=V(:,1); r=D;
        else, [c,r]=welzl_mec(V,cfg); end
        centers(:,k)=c; radii(k)=max(r,max(vecnorm(V-c)));
    end

    function yes=rangeGuaranteed(q,k)
        % 问题二思想的在线判据：若Q距整个可能区域均不超过1000 m，
        % 或Q对所有候选位置都不比上次有信号点远，则全向源必有信号。
        V=regions{k}; yes=max(vecnorm(V-q))<=1000+1e-7;
        if ~yes && all(isfinite(lastPos(:,k)))
            s=lastPos(:,k);
            yes=max(2*(s-q)'*V+q'*q-s'*s)<=1e-7;
        end
    end

    function success=clearAt(q,k)
        z=act('/clear',q,k); success=strcmp(z.clear_result,'success');
        if success, done(k)=true; cleared(k)=vt; end
    end

    function z=act(path,q,k)
        if ~strcmp(path,'/exit')&&toc(clock0)>limit-5
            error('现实时间不足，停止发送新动作。');
        end
        serial=serial+1;
        request=struct('arena_id','default','robot_id',robotId, ...
            'request_id',sprintf('p4split-%d',serial));
        if nargin>1
            request.position=struct('x',q(1),'y',q(2)); request.channel=k;
        end
        for attempt=1:3
            try
                if local, z=transport(path,request);
                else, z=webwrite([baseUrl path],request,opt); end
                break;
            catch err
                if attempt==3, rethrow(err); end
            end
        end
        assert(z.accepted,'模拟器拒绝请求：%s',jsonencode(z)); vt=z.virtual_time_s;
        if nargin>1
            if inLocal, localDistance=localDistance+norm(q-pos);
            else, globalDistance=globalDistance+norm(q-pos); end
            pos=q;
        end
        if strcmp(path,'/measure'), channel=k; end
        history(end+1,:)={path,request,z};
    end
end
